# 🧠 NOVA MIND // Sovereign Cognitive & Frontier Training Academy

**Nova Mind** adalah akademi dan sistem operasi pelatihan kognitif futuristik (*frontier training arena*) yang menggabungkan gamifikasi dopaminerjik (Brilliant + Duolingo + MasterClass), simulasi taktis real-time, dan kecerdasan buatan (*Google Gemini AI*) untuk mempercepat evolusi pola pikir dan skill tingkat tinggi.

---

## 🚀 Fitur Utama

1. **7 Frontier Faculties (Kurikulum Masa Depan)**:
   - 💻 *Deep IT, Cloud & Cyber Infrastructure* (Bare-metal kernels, io_uring, zero-trust defense).
   - ⚡ *Energy Economics & Macro Commodities* (Power grid, nuclear/hydro, energy geopolitics).
   - 🧬 *Biotechnology, Longevity & Synthetic Biology* (CRISPR, biomarkers, epigenetic clocks).
   - 🧠 *High-Order Mindset & Cognitive Warfare* (Antifragility, stoic models, cognitive defense).
   - 📈 *Stocks & Quantitative Macro Finance* (Algorithmic liquidity, order books, quant models).
   - 🪙 *Crypto, DeFi & Web3 Sovereignty* (Smart contract security, multi-sig governance).
   - 🤖 *Advanced AI & Autonomous Swarms* (LLM engineering, multi-agent swarms, prompt warfare).

2. **Live Socratic AI Mentor (Powered by Gemini API)**:
   - Widget asisten AI cerdas yang dapat diajak berdiskusi, didebat, dan menguji pemahaman secara interaktif (*Socratic Dialogue*) di setiap materi.
   - Evaluasi keamanan prompt (*Prompt Injection & Jailbreak Defense*) secara dinamis.

3. **7 Interactive Frontier Simulators**:
   - Simulator taktis interaktif langsung di browser untuk menguji keahlian praktis.

4. **Sovereign Proof of Mastery (Digital Skill Passport)**:
   - Halaman sertifikat dan passport keahlian digital dengan tracking XP, level, dan streak yang siap dibagikan ke media sosial.

5. **Acoustic Synthesizer Audio Engine**:
   - Efek suara interaktif berbasis Web Audio API untuk setiap aksi (klik, level up, streak, dan komplesi).

## ⚡ Cara Menjalankan Aplikasi

### 1. Prasyarat
- Node.js (v18 atau lebih baru)
- npm

### 2. Instalasi
```bash
npm install --legacy-peer-deps
```

### 3. Konfigurasi Environment (`.env`)
Pastikan file `.env` memiliki konfigurasi berikut:
```env
VITE_SUPABASE_URL=https://nvhmykqqetlueducpsqo.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_GEMINI_API_KEY=your_gemini_api_key
```

### 4. Menjalankan Server Lokal (Development)
```bash
npm run dev
```
Buka browser di `http://localhost:3000`.

### 5. Build Produksi
```bash
npm run build
```
